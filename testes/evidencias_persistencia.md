# Evidências de Persistência no PostgreSQL — Aula 05

Este documento reúne os registros e evidências reais da execução da **Atividade 15 — Comprovação da persistência** utilizando **Spring Boot 3**, **Spring Data JPA** e **PostgreSQL 16**.

---

## 1. Criação do Banco de Dados e Conexão Inicial

O banco de dados `api_cursos` foi criado no PostgreSQL:
```sql
CREATE DATABASE api_cursos;
```

A inicialização do Spring Boot gerou automaticamente a tabela `cursos` via Hibernate DDL (`spring.jpa.hibernate.ddl-auto=update`):
```sql
create table cursos (
    id bigint generated by default as identity,
    carga_horaria integer not null,
    nome varchar(255) not null,
    primary key (id)
);
```

---

## 2. Cadastro Inicial de Cursos (POST /cursos)

Três requisições `POST http://localhost:8080/cursos` foram enviadas para cadastrar os cursos:

### Curso 1
- **Request Body:**
  ```json
  {
    "nome": "Back-End Frameworks",
    "cargaHoraria": 60
  }
  ```
- **Response (`201 Created`):**
  ```json
  {
    "id": 1,
    "nome": "Back-End Frameworks",
    "cargaHoraria": 60
  }
  ```

### Curso 2
- **Request Body:**
  ```json
  {
    "nome": "Banco de Dados PostgreSQL",
    "cargaHoraria": 40
  }
  ```
- **Response (`201 Created`):**
  ```json
  {
    "id": 2,
    "nome": "Banco de Dados PostgreSQL",
    "cargaHoraria": 40
  }
  ```

### Curso 3
- **Request Body:**
  ```json
  {
    "nome": "Arquitetura de Software em Camadas",
    "cargaHoraria": 80
  }
  ```
- **Response (`201 Created`):**
  ```json
  {
    "id": 3,
    "nome": "Arquitetura de Software em Camadas",
    "cargaHoraria": 80
  }
  ```

## 3. Consulta Direta na Tabela do PostgreSQL (Antes do Reinício)

Comando executado diretamente no terminal via utilitário `psql`:
```bash
psql -U postgres -h localhost -p 5432 -d api_cursos -c "SELECT id, nome, carga_horaria FROM cursos ORDER BY id;"
```

**Resultado obtido:**
```
 id |                nome                | carga_horaria 
----+------------------------------------+---------------
  1 | Back-End Frameworks                |            60
  2 | Banco de Dados PostgreSQL          |            40
  3 | Arquitetura de Software em Camadas |            80
(3 linhas)
```

## 7. Conclusão da Persistência

- Os dados persistidos no PostgreSQL permaneceram intactos após o encerramento total e posterior reinicialização da aplicação.
- A camada `CursoRepository` (estendendo `JpaRepository<Curso, Long>`) realizou a recuperação dos registros do banco relacional de forma transparente.
- Critério de conclusão da Atividade 15 plenamente atendido.
